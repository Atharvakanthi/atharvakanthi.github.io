Data Analyst Agent

A multi-agent framework I designed at Avacasa that turns a business enquiry into a finished, reviewed market report. Each stage of an analyst's job is handled by a specialist agent, and nothing ships until it has passed three full review rounds.

1 week → 2 daysreport creation time
8 agentsfrom intake to design review
3 roundsof full-read review before delivery

How it works

What each agent does

AgentJob
IntakeReads the enquiry, works out what it is asking, and breaks it into predefined analysis buckets. The buckets become the report template.
Data retrievalSearches the internal database for each bucket. Where data is missing, it sends a request to the data-collection system and waits for the data to come back.
Data analystCleans and standardises the data and runs the analysis: segmentation, benchmarks, distributions, trends.
Business analystChecks the output against the business requirement and transforms it into what the reader needs to decide.
ReviewerReviews the analysis for errors and gaps before anything is designed.
DesignerBuilds the report: layout, charts, maps and tables.
Design reviewerChecks that every element has rendered correctly.
Final review ×3Three separate rounds that read the whole report with its graphs and confirm it is correct. Any problem is sent back to the agent responsible.

Example output

The Athimuthlu farmland competitive benchmark was produced end-to-end by this system: a location profile, comparable projects across managed farmland, plotted and villa segments, resale analysis and an interactive map. A public version with client details removed is being prepared.

The code runs on Avacasa's internal database and collection systems, so it is not public. This page describes the architecture and results only.
